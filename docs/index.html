Auto-Pearson

A Chrome extension for Pearson MyLab homework. Send a question to your chosen AI chat, review the filled answer, and move to the next part after positive feedback.

Download v0.6.1 · Installation guide

Review before submitting

Keep the default pause on to inspect the first answer. Screenshot mode sends the whole visible homework tab to the chat, including any course or account details on screen.

Supported workflows

The extension targets MyLab homework and offers Gemini, ChatGPT, and DeepSeek chat adapters. Course layouts and provider interfaces vary. The repository includes simulated tests for success dialogs and multi-part questions.
